# Проект homework_10_1

## Описание проекта:

Проект homework_10_1 - работа над виджетом банковских операций клиента.


## Возможности

- 📂 Чтение данных из форматов JSON, CSV и XLSX.
- 💱 Конвертация валют (USD, EUR) в рубли через API apilayer.
- 🔒 Маскировка номеров карт и счетов.
- 📊 Подсчет статистики по транзакциям (суммы по валютам).
- 📝 Гибкое логирование (запись логов в файл).


## Установка:

1. Клонируйте репозиторий:
```bash
git clone https://github.com/Nap001-lol/homework_10_1.git
cd homework_10_1
```

2. Создайте виртуальное окружение и активируйте его:
```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Mac/Linux:
source .venv/bin/activate
```

3. Установите зависимости:
```bash
poetry install
```

4. Настройте переменные окружения:
- Скопируйте файл .env.example в .env
- Откройте .env и впишите ваш API_KEY для apilayer.


## Структура проекта:
- `data/` — файлы с данными в формате json.
- `data_df/` — файлы с данными в формате Excel/CSV.
- `decorators/` — директория автоматической регистрации деталей выполнения функций.
- `logs/` — папка записи логов (игнорируется в git).
- `src/` — исходный код (модули для работы с API, утилиты, маскировка).
- `tests/` — тесты (pytest).

## Стек технологий:
- **Основные:** requests, python-dotenv, pandas, openpyxl
- **Тестирование:** pytest, pytest-cov
- **Качество кода:** flake8, black, mypy, isort, pandas-stubs

## Запуск тестов
Чтобы запустить тесты, выполните:

pytest
